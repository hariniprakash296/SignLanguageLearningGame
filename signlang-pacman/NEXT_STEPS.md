# Next Steps

Great! You've successfully added the `GEMINI_API_KEY`.

## 🔄 Action Required
**Please restart your development server** for the new environment variables to be loaded:

1. Stop the current server (`Ctrl+C` in your terminal).
2. Run `npm run dev` again.

## 🧪 What to Test

### 1. Level 2 (Initialized Signs)
- Navigate to **Level 2** in the game.
- Try the **FAMILY** sign:
  - Make the 'F' handshape.
  - Move your hand in a horizontal circle/arc.
  - You should see feedback like "Perfect movement!".

### 2. AI Interpreter (Translator Tab)
- Go to the **Translator** tab.
- The camera should auto-start.
- Sign something (e.g., 'A' or 'FAMILY').
- The system will use the Gemini API to provide a translation.
